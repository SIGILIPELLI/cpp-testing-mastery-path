# C/C++ Testing Mastery Path

A free, structured, module-wise software testing program for C and C++ — manual
QA fundamentals through automated unit testing, sanitizers, fuzzing and CI,
entry level to master level, with a hands-on project at the end of each level.

**Live site:** https://sigilipelli.github.io/cpp-testing-mastery-path/

## Contents

- **Level 1 · Entry** — testing fundamentals, test case design, defect
  reporting, and your first GoogleTest/CTest suite
- **Level 2 · Intermediate** — GoogleMock, sanitizers, coverage, static analysis
- **Level 3 · Advanced** — integration, embedded targets, fuzzing, CI/CD,
  concurrency and legacy code
- **Level 4 · Master** — test architecture, safety-critical standards,
  traceability, quality gates and in-house frameworks
